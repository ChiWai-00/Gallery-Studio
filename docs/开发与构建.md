# 开发与构建

## 技术栈

纯 HTML、CSS、原生 JavaScript；无需框架、网络接口、数据库、npm 或第三方构建依赖。`src/assets/examples/` 为原始示例资源。`dist/index.html` 是由脚本注入 CSS、JavaScript 和图片数据得到的自包含单文件发布版。

## 源码开发

编辑 `src/index.html`、`src/styles.css`、`src/app.js`。为避免浏览器 `file://` 的本地资源限制，可从仓库根目录运行：

```bash
python -m http.server 8000 --directory src
```

然后打开 `http://localhost:8000`。修改内置示例图时替换 `src/assets/examples/01.jpg` 至 `03.jpg`，建议保持 900×1200；对应名称和宽高元数据在构建脚本中定义。

## 打包发布

```bash
python scripts/build.py
```

构建会覆盖 `dist/index.html`。脚本仅依赖 Python 3 标准库，不需要联网。

## 代码导览

- `src/index.html`：上传区、预览区、导出区及创作者署名。
- `src/styles.css`：页面主题、分栏、响应式布局、自定义下拉、拖拽视觉反馈和署名。
- `src/app.js`：`useDemo` / `render` / `setupMousePreview` 负责预览；拖拽排序逻辑负责顺序；`copyMode` 是微信富文本复制；`copyObsidian` 是 Obsidian HTML 源码复制；`buildStandalone` 是离线 HTML 阅读页导出；`initPrettySelects` 是自定义下拉菜单。
- `scripts/build.py`：把三张示例图编码成 Base64，生成不需要旁边再放图片/CSS/JS 的 `dist/index.html`。

## 提交前自检

1. 运行 `python scripts/build.py`。
2. 用浏览器打开 `dist/index.html`，检查示例、拖拽排序、下拉菜单、预览和独立 HTML 下载。
3. 分别在微信公众号草稿和 Obsidian 试粘贴，并记录实际版本/环境；不应仅凭复制成功就判定兼容。
