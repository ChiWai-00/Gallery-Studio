# 平台兼容性与限制

本项目的主要目标是帮助用户本地制作并预览横滑组图。**浏览器本地能横滑，不能证明微信或 Obsidian 一定会横滑。**

## 微信公众号

- 微信图文编辑器可能过滤 `overflow-x`、`display:flex` 等布局样式。
- 直接粘贴本地 Base64 图片可能被剔除，或不能在微信中加载。
- 高级设置可以粘贴已在公众号上传过的图片 URL，但只提高图片来源的可用性，不代表横滑样式能保留。
- 这是「兼容测试」功能，不应宣传为已经完成官方集成或永久稳定。

## Obsidian

- 「复制到 Obsidian」复制的是包含 HTML 的纯文本。压缩图片以 Base64 的形式嵌入笔记 `.md` 中，**不生成附件**。
- Obsidian 可能对 HTML 属性进行安全处理，主题、版本、阅读/实时预览模式也可能影响最终效果。
- Base64 内嵌组图会增加笔记体积，影响同步和版本管理，不适合无限量大型组图。
- 不同系统/应用可能对大剪贴板有大小限制，若失败请减少图片数量。

## 独立 HTML 阅读页

- 使用浏览器本地渲染，可获得相对完整的横滑体验。
- 不等于能把 HTML 文件直接嵌入微信公众号正文。
- 该 HTML 包含用户添加的图像数据，若用来共享，请检查图片版权与隐私。

## 隐私

- 当前工具没有自建云服务、账号系统、分析脚本或遥测。
- 导入图片通常只在浏览器本地处理。
- 用户若主动填写外部图像网址，浏览器可能向该地址发起访问；请不要使用含敏感令牌的链接。
