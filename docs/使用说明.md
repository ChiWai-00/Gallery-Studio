# 使用说明

## 1. 打开软件

从项目的 [Releases](https://github.com/ChiWai-00/Gallery-Studio/releases) 下载单文件成品 `GalleryStudio_ChiWai_v1.0.0.html`，Windows 电脑使用 Chrome 或 Edge 双击打开。无需安装。页面中会显示三张原创浅色示例海报。也可以通过运行 `python scripts/build.py` 自行构建 `dist/index.html`。

## 2. 添加自己的图片

在「添加与排序」区域点击「添加图片」，或拖入多个 JPG、PNG、WebP、GIF 文件。首次导入自己的图片会替换示例图。可继续添加，最多 30 张。

## 3. 调整顺序和样式

按住图片左侧的六点拖拽手柄调整顺序；也可以使用「上移」「下移」。中间预览支持鼠标拖动、触摸横滑、前后按钮和方向键。右侧选择画面比例、图片适配方式、留白背景和提示文字。

## 4. 导出

### 独立 HTML

点击「下载离线翻阅网页」，生成包含图片数据的独立 `.html` 文件。可用浏览器离线打开；不需要上传图片到服务器。**它不是公众号可直接嵌入的组件。**

### 微信公众号（实验性）

点击「复制到公众号」，在公众号图文编辑区粘贴，再保存草稿、发到手机微信预览。微信可能过滤横滑 CSS 和 `data:` 图片；高级设置可绑定微信已经托管的图片 URL，但仍不保证滑动样式能保留。

### Obsidian（实验性）

点击「复制到 Obsidian」，再到笔记编辑模式按 `Ctrl+V`，切换阅读模式检查效果。工具会将压缩图片直接编码进笔记 `.md` 文件，不会生成独立附件。若主题或 Obsidian 安全过滤器不支持这些样式，可能无法横滑。建议先测试三张示例图，不要直接粘贴大量图片。

## 5. 常见问题

- **复制成功但没出现横滑？** 剪贴板复制只代表内容已写入，目标平台可能过滤样式。请查看目标平台的手机/阅读模式预览。
- **网页打开看不到图片？** 请使用 Releases 的单文件版，或在源码仓库运行 `python scripts/build.py` 后打开生成的 `dist/index.html`；源码 `src/index.html` 使用独立资源，开发时应通过本地 HTTP 服务访问。
- **Obsidian 的图片在哪里？** 直接在 `.md` 中，以 Base64 文本嵌入，不在附件文件夹。
- **浏览器提示没有剪贴板权限？** 尝试在 Chrome/Edge 中开启相关权限；本地 `file://` 的权限行为可能受浏览器限制。
